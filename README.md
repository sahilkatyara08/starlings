# starlings

A live murmuration of starlings drawn in ASCII glyphs, steered from a frosted glass dock.

- **Behaviours:** Murmur, Stream, Gather, Roost (keys 1–4)
- **Palettes:** Slate, Sundown, Embers, Fern, Frost, Pebble (arrow keys)
- Move the cursor through the flock to scatter it like a falcon; click to startle it.

Single static `index.html` (vanilla JS + canvas, boids simulation). No build step: deploy as-is on Vercel or any static host. Respects `prefers-reduced-motion`.

Fonts: Inter and JetBrains Mono via Google Fonts (SIL Open Font License).
